# RentMate
An end-to-end Java-powered online rental system

**RentMate** is a full-stack web-based application built with Java Servlets, JSP, and MySQL that provides a seamless platform for renting home appliances and products within a city. Users can browse, book, and pay for products online, while admins can manage listings and monitor transactions efficiently.

---

## 🚀 Features & Functionalities

### 👥 User Module
- **User Registration & Login** – Secure authentication using sessions.
- **Product Browsing** – Search and filter rental items by category.
- **Item Details Page** – View product descriptions, images, and pricing.
- **Booking System** – Select rental duration with date pickers.
- **Razorpay Integration** – Simulated payment flow using sandbox API.
- **Invoices** – Auto-generated downloadable invoices after successful payment.
- **Feedback Submission** – Users can submit feedback for service improvement.
- **Contact Form** – Allows users to reach out for help or queries.

### 🔧 Admin Module
- **Admin Authentication** – Secure login for admin users.
- **Inventory Management** – Add, update, or delete rental items.
- **Booking Overview** – View all bookings and their statuses.
- **Feedback View** – Monitor user feedback.
- **Transaction Monitoring** – Track payments and generate reports.
